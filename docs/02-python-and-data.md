# 02. Python and data, from a gentle start

**Beginner to intermediate · 5 hours to ~300 hours per certification**

> Learn enough code to read, run, and modify something real—then use it to understand a dataset honestly.

[Guide home](README.md) · [Certificate guide](certificates.md) · [Learning paths](learning-paths.md) · [Full library](full-library.md)

A Python course is not the same thing as an AI course, but it is the on-ramp that makes modern AI practice possible. Start here if you want to build tools rather than only talk about them.

Kaggle is the lowest-friction starting line: short browser notebooks, immediate feedback, and a free completion certificate. Python takes about five hours and pandas about four. You can finish the first one this week without installing anything; install Python locally only when you want to keep working offline.

The long freeCodeCamp certifications are a different commitment. Each is project-based and estimated at roughly 300 hours. They can be excellent evidence of persistence, but they are a poor first test of whether you enjoy coding. Use the freeCodeCamp YouTube channel or early curriculum sections as a sample before promising yourself a marathon.

DeepLearning.AI's AI Python for Beginners is useful once you can write a basic script and want an AI-assisted, project-oriented next step. Its lessons are free to watch; labs, quizzes, and certificates on its own platform require DeepLearning.AI PRO. Keep API keys in environment variables and never commit them.

**Best for:** Beginners who want a practical coding foundation, spreadsheet users ready to graduate, and builders who need enough Python to work with APIs and data.

## Courses, one by one

### [Kaggle: Python](https://www.kaggle.com/learn/python)

**Kaggle Learn** · Beginner · 5 hours · Interactive notebooks

Five hours of hands-on Python in the browser: variables, functions, loops, lists, dictionaries, and importing libraries. Short coding exercises and a free completion certificate make it a low-friction first coding step.

- **Access:** Free
- **Certificate:** Free Kaggle Learn completion certificate after finishing the course exercises.
- **Topics:** Python, Coding, Notebooks

### [Kaggle: Pandas](https://www.kaggle.com/learn/pandas)

**Kaggle Learn** · Beginner · 4 hours · Interactive notebooks

Four hours of practical data wrangling with pandas: selecting, filtering, grouping, joining, and cleaning real tabular data. Finish with a free certificate and the skills to inspect a dataset without panic.

- **Access:** Free
- **Certificate:** Free Kaggle Learn completion certificate.
- **Topics:** Pandas, Data, Python

### [AI Python for Beginners](https://www.deeplearning.ai/short-courses/ai-python-for-beginners/)

**DeepLearning.AI** · Beginner · 11.5 hours · Short course

A friendly 11.5-hour introduction to Python with an AI helper. Cover variables, functions, data, and small projects; no coding background required. The lessons are free, and the pace is yours.

- **Access:** Free lessons

- **Topics:** Python, APIs, Beginner coding

### [Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python)

**freeCodeCamp** · Beginner · ~300 hours (self-paced) · Interactive curriculum + projects

Learn NumPy, pandas, Matplotlib, and Seaborn through lessons and five data-analysis projects, with a free certification at the end. A practical, long-form path for people who like to learn by building.

- **Access:** Free
- **Certificate:** Free freeCodeCamp certification after completing the required projects.
- **Topics:** Data analysis, Python, Visualization

**freeCodeCamp** · Beginner · ~300 hours (self-paced) · Interactive curriculum + projects

## Certificate reality

Kaggle's Python and pandas certificates are free after you complete the exercises. freeCodeCamp's certifications are free after the required projects; each is a long course, not a quick badge. DeepLearning.AI's certificate is tied to paid PRO access, even though its lesson videos are free to watch.

A completion certificate is a record that you finished a defined piece of learning. It is not an accredited degree, a professional license, or proof that you can do the work unsupervised. See [the certificate guide](certificates.md) for the provider-by-provider rules.

## A small proof of work

Build a small local notebook with a fabricated or public CSV: load it, clean one messy column, make two charts, and write five sentences that include one limitation of the data.

## Where next

Carry the same dataset into the machine-learning shelf, where you will train a first model and learn to evaluate it with more honesty. Open [the matching learning path](learning-paths.md#python-and-data) for a longer sequence, or return to [the guide index](README.md) to choose another shelf.
