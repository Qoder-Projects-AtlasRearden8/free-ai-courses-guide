01
Beginner · No code

Understand AI without the jargon

A calm on-ramp for curious adults who want to use AI thoughtfully and explain it clearly.

Build a working vocabulary, practice a repeatable prompt loop, and develop the judgment to notice when AI is helpful, wrong, or inappropriate.

0 of 8 resources done
LevelBeginner
Time4–6 weeks
Weekly effort3–4 hours per week
Best forNurses, writers, small-business owners, parents, and anyone who keeps hearing AI terms they are too polite to ask about.
PrerequisitesNone. No math, no coding, no prerequisite course.
CertificatesOne free Google badge and one free Kaggle certificate are available in this route.
  1. 01

    Get the big picture

    Start with a 45-minute explanation and a friendly university course. The goal is not to memorize terms; it is to replace vague anxiety with a few accurate sentences.

    Google Introduction to Generative AI (opens in a new tab) 45 min · Beginner · Free certificate
    University of Helsinki Elements of AI: Introduction to AI (opens in a new tab) ~30 hours · Beginner
  2. 02

    Learn how machines learn

    Skim Google's ML fundamentals and watch one visual explanation. You are building a mental model of training, prediction, and error—not becoming an engineer in a weekend.

    Google Machine Learning Crash Course (opens in a new tab) ~15 hours · Beginner
    3Blue1Brown 3Blue1Brown (opens in a new tab) Watch 2–3 videos · All levels
  3. 03

    Practice a real prompt

    Take a short prompting course, then use Google's whitepaper to understand why one prompt works better than another. Test everything on a low-stakes, non-sensitive task.

    DeepLearning.AI ChatGPT Prompt Engineering for Developers (opens in a new tab) 1 hr 40 min · Beginner
    Google Prompt Engineering (Google Whitepaper) (opens in a new tab) ~1 hour · Intermediate
  4. 04

    Build your judgment

    Use an ethics course and a human-centered design guide to make your own rules for privacy, verification, disclosure, and when to stop and ask a person.

    Kaggle Learn Kaggle: Intro to AI Ethics (opens in a new tab) 4 hours · Beginner · Free certificate
    Google People + AI Guidebook (opens in a new tab) 3–4 hours · Intermediate
The finish line

A one-page AI field note

Write a plain-English explanation of generative AI in five paragraphs, include a prompt template you tested, and finish with five personal rules for safe use.

Proof of work: A document you could hand to a colleague. Bonus: record a five-minute voice note explaining it without jargon.

Then what? Move to the Python and data foundations route if you want to make tools yourself, or stay here and deepen your practice with the 30/60/90-day plan.

02
Beginner → Intermediate · Code

Python and data, without the bootcamp

A practical foundation for people who want to clean data, train a first model, and know when the result is believable.

Learn just enough Python to be dangerous, get comfortable with tabular data, build a first model, and tell an honest story about what it can and cannot prove.

0 of 10 resources done
LevelBeginner to intermediate
Time12 weeks–6 months
Weekly effort5–6 hours per week
Best forAnyone willing to practice a little code each week. Useful for authors tracking sales, small businesses studying demand, or healthcare workers learning with public data.
PrerequisitesComfort using a browser and editing a spreadsheet. No prior programming required, but consistency is.
CertificatesKaggle certificates are free and quick; freeCodeCamp certifications are free but long.
  1. 01

    Python on-ramp

    Use Kaggle's short in-browser course as the required spine. Keep freeCodeCamp's larger certification in reserve for when you want a long, project-based credential.

    Kaggle Learn Kaggle: Python (opens in a new tab) 5 hours · Beginner · Free certificate
    freeCodeCamp Scientific Computing with Python (opens in a new tab) ~300 hours (self-paced) · Beginner · Free certificate
  2. 02

    Make data less scary

    Learn pandas through small exercises, then use freeCodeCamp's data-analysis curriculum for deeper project practice. Pick a public dataset you actually find interesting.

    Kaggle Learn Kaggle: Pandas (opens in a new tab) 4 hours · Beginner · Free certificate
    freeCodeCamp Data Analysis with Python (opens in a new tab) ~300 hours (self-paced) · Beginner · Free certificate
  3. 03

    Train a first model

    Build a decision tree and random forest in Kaggle, then use Google's crash course to understand what the model is optimizing and where it can fail.

    Kaggle Learn Kaggle: Intro to Machine Learning (opens in a new tab) 3 hours · Beginner · Free certificate
    Google Machine Learning Crash Course (opens in a new tab) ~15 hours · Beginner
  4. 04

    Get honest about evaluation

    Learn about validation, missing data, and pipelines. Read Machine Learning Yearning for the project-level judgment that code tutorials often skip.

    Kaggle Learn Kaggle: Intermediate Machine Learning (opens in a new tab) 4 hours · Intermediate · Free certificate
    DeepLearning.AI Machine Learning Yearning (opens in a new tab) ~3 hours · Beginner
  5. 05

    Make a portfolio project

    Only after the smaller pieces feel familiar, choose a long freeCodeCamp certification or go deeper into neural networks with Kaggle. Use the other as optional follow-up.

    freeCodeCamp Machine Learning with Python (opens in a new tab) ~300 hours (self-paced) · Intermediate · Free certificate
    Kaggle Learn Kaggle: Intro to Deep Learning (opens in a new tab) 4 hours · Intermediate · Free certificate
The finish line

One honest data story

Choose a public, non-sensitive dataset. Ask one clear question, establish a baseline, train a simple model, and report one meaningful limit alongside your result.

Proof of work: A clean notebook and a one-page README with the question, data source, method, metric, and 'what this does not prove'.

Then what? You are ready for the builder route: LLM applications, agents, and MCP. Or continue into deep learning for a more mathematical route.

03
Intermediate · Build

Build with LLMs, agents, and MCP

From a first API call to a small agent that uses tools—with free certificates available along the way.

Learn how LLM applications are put together, how agents use tools, and how MCP connects models to outside data. Each stage ends with something small you can run.

0 of 11 resources done
LevelIntermediate
Time12 weeks–4 months
Weekly effort5–8 hours per week
Best forPeople who can already write a little Python and want to build useful, local-first tools rather than only chat with a model.
PrerequisitesBasic Python (variables, functions, lists, a little file handling), comfort with the command line, and patience with error messages.
CertificatesHugging Face offers free Agents and MCP certificates. DeepLearning.AI lessons are free; its certificates require PRO.
  1. 01

    Python and API confidence

    Fill the coding gaps with DeepLearning.AI's beginner Python course. Skim Microsoft's Generative AI curriculum for the app-building vocabulary, not as a race.

    DeepLearning.AI AI Python for Beginners (opens in a new tab) 11.5 hours · Beginner
    Microsoft Generative AI for Beginners (opens in a new tab) 21 lessons (self-paced) · Beginner
  2. 02

    Understand the model layer

    Work through the first chapters of the Hugging Face LLM course. Focus on tokens, transformers, datasets, and evaluation before trying to fine-tune anything.

    Hugging Face Hugging Face LLM Course (opens in a new tab) 6–8 hours per chapter · Intermediate
  3. 03

    Prompt, call, and constrain

    Use DeepLearning.AI's prompting short course to turn a fuzzy idea into instructions, then enforce a format in code. Keep API keys in environment variables, never in your repo.

    DeepLearning.AI ChatGPT Prompt Engineering for Developers (opens in a new tab) 1 hr 40 min · Beginner
    DeepLearning.AI MCP: Build Rich-Context AI Apps with Anthropic (opens in a new tab) ~2 hours · Intermediate
  4. 04

    Build your first agent loop

    Learn the goal → tool → observation → stop loop. Take Hugging Face's Agents course for structured practice, with Microsoft's AI Agents curriculum as a second perspective.

    Hugging Face Hugging Face AI Agents Course (opens in a new tab) 3–4 hours per unit · Intermediate · Free certificate
    Microsoft AI Agents for Beginners (opens in a new tab) 18 lessons (self-paced) · Intermediate
  5. 05

    Connect tools safely with MCP

    Build an MCP mental model with the Hugging Face course, then use Microsoft's curriculum and the official docs when you need implementation detail. Start read-only, with explicit permissions.

    Hugging Face Hugging Face MCP Course (opens in a new tab) 3–4 hours per unit · Intermediate · Free certificate
    Microsoft MCP for Beginners (opens in a new tab) 15+ modules (self-paced) · Intermediate
    Model Context Protocol Model Context Protocol Documentation (opens in a new tab) Reference · Advanced
  6. 06

    Ship a small capstone

    Use the Kaggle/Google agent intensive for structure and community, or design your own project. The finish line is a tested tool with a README—not a folder of half-finished demos.

    Kaggle Learn 5-Day AI Agents Intensive Course with Google (opens in a new tab) 5 days + project · Intermediate
The finish line

A small tool with a tool-use boundary

Build one narrow agent or MCP-connected app: a reading-log helper, a public-data lookup, or a local document Q&A tool. Use synthetic or public data, require confirmation before any write action, and document what it cannot do.

Proof of work: A public repo or local project with setup steps, a demo, a privacy note, and evidence that it runs from a clean start.

Then what? Go deeper into evaluation, observability, and security. Or use the finished project as the foundation for an ASDALE DYNAMICS template or small product.

04
Advanced · Theory + practice

Deep learning, from first principles

A slower, more rigorous route for people who want to understand the machinery, not only use the API.

Use code-first courses to keep momentum, open textbooks to fill the math, and primary lectures to see how the field reasons. Expect to loop back, not master everything in one pass.

0 of 11 resources done
LevelAdvanced
Time6–9 months
Weekly effort6–10 hours per week
Best forBuilders who have finished a first ML project and now want the math, model internals, and research habits behind modern deep learning.
PrerequisitesComfortable Python, basic calculus and linear algebra, and at least one machine-learning course or equivalent project experience.
CertificatesKaggle's Intro to Deep Learning certificate is free. The most valuable output here is a reproducible project and model card.
  1. 01

    Refresh the math you need

    Use selected chapters of Mathematics for Machine Learning and visual videos. Aim for intuition about vectors, gradients, and probability—not exam perfection.

    MML Book Mathematics for Machine Learning (opens in a new tab) Reference · Advanced
    3Blue1Brown 3Blue1Brown (opens in a new tab) Watch 2–3 videos · All levels
  2. 02

    Build first

    Take fast.ai's code-first course alongside its free book. Train models, break things, and develop a feel for learning rates, overfitting, and data quality before diving into proofs.

    fast.ai Practical Deep Learning for Coders (opens in a new tab) 9 lessons (~90 min each) + practice · Intermediate
    fast.ai Deep Learning for Coders with fastai and PyTorch (opens in a new tab) 20+ hours · Intermediate
  3. 03

    Connect theory to implementation

    Read and run Dive into Deep Learning, then complete Kaggle's short deep-learning course as a checkpoint. Rewrite at least one model from scratch in a small notebook.

    D2L.ai Dive into Deep Learning (opens in a new tab) Semester-scale · Advanced
    Kaggle Learn Kaggle: Intro to Deep Learning (opens in a new tab) 4 hours · Intermediate · Free certificate
  4. 04

    Learn from primary lectures

    Watch MIT 6.S191 and selected Andrej Karpathy lectures. Take notes as if you will explain each idea to a smart colleague who has never trained a model.

    MIT MIT Introduction to Deep Learning (6.S191) (opens in a new tab) Semester lectures + labs · Advanced
    Andrej Karpathy Andrej Karpathy (opens in a new tab) Watch one lecture · Advanced
  5. 05

    Read the reference shelf

    Use Deep Learning as a reference when a concept will not click, and An Introduction to Statistical Learning to keep classical machine learning in view. You are not required to read every page.

    MIT Press Deep Learning (opens in a new tab) Reference · Advanced
    StatLearning An Introduction to Statistical Learning (opens in a new tab) Long reference · Intermediate
  6. 06

    Fine-tune and document

    Use the Hugging Face LLM course for a guided fine-tuning or evaluation project, then write a model card with intended use, limits, data provenance, and failure cases.

    Hugging Face Hugging Face LLM Course (opens in a new tab) 6–8 hours per chapter · Intermediate
The finish line

A reproducible model study

Choose a public dataset or small open model. Establish a baseline, test one clear hypothesis, document the compute budget, evaluate beyond a single score, and state who should not rely on it.

Proof of work: A reproducible repository, training log, evaluation table, and a model card written for a non-expert reader.

Then what? Specialize in evaluation, interpretability, efficient fine-tuning, or safety—and keep a small project shipping while you read.

Still deciding?

Four honest questions.

You do not need to predict your whole future. Pick the route that fits the next month, then let the work tell you what comes next.

01

Do you want to understand AI before you touch code?

Take Understand AI without the jargon. It is calm, no-code, and useful for explaining AI to other people.

02

Do you want to work with data and maybe change jobs?

Take Python and data, from zero. It builds the mechanics slowly enough to keep.

03

Do you want to build tools with models, agents, or MCP?

Take Build with AI after a little Python—or after you have shipped one small script.

04

Do you already have Python and basic ML?

Take Go deeper into deep learning. It is the advanced route, with university-scale reading and labs.

Every route uses free-to-learn resources. Some certificates cost money, and the path facts say so before you commit.

How to use a path

Follow the spine. Skip the noise.

Paths are sequences, not contracts. If a resource is not working, substitute something from the library that teaches the same idea—then keep the project.

Do the small applied work even when it feels early. Watching someone else build something is not the same skill as building it badly, checking it, and making it a little better.

At the end of each step, write one sentence: “I can now…” If you cannot finish the sentence without jargon, revisit the practice—not the certificate.
